# Versões dos repositórios que o Airflow executa em produção (servidor atb)
#
# REGRA: prod roda EXATAMENTE estes commits. Em dev o docker-compose.override.yml
# monta o working tree de ~/workspace e este arquivo não é usado.
#
# Promover = trocar o SHA, em commit próprio, para ficar visível no histórico e
# ser fácil de reverter. Pegue o SHA com:
#   git -C ~/workspace/my_ingestion rev-parse origin/main
#
# O deploy popula os diretórios com:
#   deploy/checkout_versions.sh <destino>
# e monta <destino>/my_ingestion/src e <destino>/my_analytics nos mesmos caminhos do
# container de dev (/usr/local/airflow/include/my_ingestion/src e
# /usr/local/airflow/dbt/my_analytics).
#
# Formato: nome sha url
